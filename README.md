# 懒人衣橱 · 衣序天气穿搭

把衣橱拍照录入，按天气、场合与你的体感生成一套能直接穿出门的搭配。

整个应用只有一个 `index.html`，无需安装、无需构建、不依赖任何外部框架。衣物数据保存在你自己的浏览器里。

## 打开方式

**在线直接用**：<https://jiang2588.github.io/lanren-yichu/>

**推荐：双击 `启动.cmd`**

它会用电脑上的 Python 起一个仅限本机的临时服务并打开浏览器，关闭弹出的命令行窗口即停止服务。这样浏览器会把数据稳定存进 IndexedDB。

**也可以直接双击 `index.html`**

完全可用。部分浏览器会限制本地文件的 IndexedDB，此时应用会自动回退到 localStorage，功能不受影响，只是容量较小。

手机使用：把整个文件夹放到手机能访问的位置，用浏览器打开 `index.html`；或部署到任意静态托管。

## 主要功能

### 扫描录入（本地处理）

- 拍照或一次多选上传，最多 8 张；失败项可单独重试，也可随时移除。
- 在浏览器本地完成：主体裁剪、背景去除、透明边缘羽化、主色 / 辅色提取、类别 / 保暖度 / 季节 / 风格建议。
- 每个识别结果都显示置信度；类别、保暖、风格、名称、图案、版型、防雨与适用季节都可在卡片内直接修正，也可保存后再编辑。
- 输出优先使用带透明通道的 WebP，浏览器不支持时回退 PNG；背景过于复杂时自动退化为中心裁剪，并在卡片上标明。
- 所有识别不上传图片，不依赖云端模型。

**准确率边界（实测与设计预期）**

- 类别建议约 60–75% 准确，依赖干净背景、居中摆放与完整轮廓；叠放衣物、长袖平铺、连体裤等容易混淆。清晰单件样本可达到 60–75% 区间上限。
- 主色较稳定；辅色在花纹、阴影、深色边缘下可能偏差。
- 图案（条纹 / 格纹 / 印花）与防雨无法可靠识别，默认低置信度，需手动确认。
- 浅色衣物贴近浅色背景、透明材质、毛绒边缘、强烈阴影时，去背可能不完整或退化为中心裁剪。

### 衣橱与数据

- 分类筛选、编辑、删除、清空；首次可载入 12 件示例快速体验。
- 优先 IndexedDB，失败自动回退 localStorage；刷新、关闭浏览器后数据仍在。
- JSON 导出全部衣物；导入时按 ID 合并，方便换设备或备份。

### 天气

- 按城市调用免密钥的 Open-Meteo，获取温度、体感、降水概率、风力与今日高低温；记住上次城市。
- 无网络或接口失败时，可手动填写温度 / 天气 / 降水 / 风力继续使用。

### 搭配与评分

- 搭配条件：场合（通勤 / 约会 / 运动 / 居家 / 正式）、体感（我怕冷 / 适中 / 我怕热）、降雨（按天气 / 有雨 / 无雨）、色系（不限 / 中性 / 暖色 / 冷色）。
- 合法组合为上装 + 下装 + 鞋，或连衣裙 + 鞋；按温度、风、雨自动决定是否加外套，配饰可选。
- 评分覆盖保暖、防雨防风、颜色和谐、色系偏好、图案数量、风格一致、场合匹配、廓形比例、新鲜度与偏好学习；满分 100，详情页逐项显示。
- 「喜欢 / 不喜欢」会微调单品与风格权重，逐步影响后续推荐；可随时在设置中重置。
- 锁定喜欢的单品后重新生成；「换一套」会避开当前这套并参考最近 3 天的穿着记录。
- 推荐理由会说明保暖、天气、配色、场合与偏好学习的作用。
- 今日搭配以立体衣柜呈现：柜门向两侧旋开，衣物按上装 / 下装 / 鞋履 / 配饰的顺序逐件弹出，带景深、软阴影与轻微悬浮；点击任意衣物可直接编辑。
- 搭配详情页包含拼贴、条件、评分条与完整理由。
- 分享图：1080×1350 PNG，圆角卡片、场合与色系信息，无任何第三方水印或作者署名。

## 使用流程

1. 打开应用，点「扫描录入」上传照片；检查置信度与建议，必要时修正，然后加入衣橱。或先「载入示例衣橱」。
2. 点天气区的「更新天气」输入城市，或「手动填写」直接给一个温度。
3. 在「今天穿什么」选择场合、体感、降雨与色系，生成搭配；可锁定单品再「换一套」。
4. 用「喜欢 / 不喜欢」记录偏好；打开「详情与评分」查看逐项分数与理由。
5. 需要备份时，打开右上角设置，导出 JSON。

## 数据与隐私

- 衣物图片与属性只存在当前浏览器，不上传服务器，无账号、无追踪。
- 扫描识别完全在本地 Canvas / JavaScript 中完成，不调用云端模型。
- 唯一联网行为是查询 Open-Meteo 天气，接口不需要密钥。
- 清除浏览器站点数据会删除衣橱，建议定期导出 JSON 备份。

## 已知限制

- 搭配评分是启发式规则，不判断材质厚薄的真实物理性能；类别、保暖度等以识别建议与手动确认为准。
- 图片统一压缩；带透明通道的扫描结果优先 WebP，不支持时回退 PNG。HEIC 等浏览器不支持的格式可能读取失败，建议用 JPG / PNG。
- 直接以 `file://` 打开时，个别浏览器会禁用 IndexedDB，应用会回退到 localStorage，容量约 5MB；衣物较多时请用「启动.cmd」或静态托管。
- 天气需要联网；离线时只能手动填写。手动天气会标记为「手动填写」，不会自动覆盖。
- 分享图由 Canvas 在本地绘制，依赖浏览器对 Canvas 与图片解码的支持。
